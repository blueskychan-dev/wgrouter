Add a device

Leave blank to take the lowest free address.

The device routes only the tunnel pool. Correct for every peer reached through a masquerade forward, which is the default.

For a peer that is the target of a direct-mode forward. Direct mode delivers the client's real source address, which requires AllowedIPs = 0.0.0.0/0 — that value is the inbound cryptokey filter, not just a route.

On its own that would also become the device's default route, and this tunnel has no internet egress, so the device would lose connectivity. The generated config therefore sets Table = off and installs source-based policy routing instead: replies from the tunnel address leave through the tunnel, and the system default route is untouched. It needs wg-quick on Linux — the hooks are ip route/ip rule commands, which phone clients cannot run.

Baked into the config at creation and not changeable later.
