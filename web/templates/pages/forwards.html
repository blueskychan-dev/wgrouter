Source address modes

Masquerade
Always works, no client-side requirements. The peer sees the router's tunnel address instead of the real client, so the origin is recorded in the connection log instead.
Direct
The peer sees the real client address. The peer's own AllowedIPs must cover the clients it replies to — usually 0.0.0.0/0. With the default AllowedIPs of just the tunnel pool, replies leave by the peer's normal route instead and connections hang.
Forwards are programmed as nftables rules in the dedicated inet wgrouter table, rebuilt from the database on every change. Remember that a cloud firewall — an OCI security list or AWS security group — must also allow the WAN port, or the rule will be correct and still unreachable. The per-forward connection log arrives with the source-preservation milestone.
