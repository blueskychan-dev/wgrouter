Export

Contents
{{.CountPeers}} device(s), {{.CountForwards}} forward(s) and the router's settings.

Logs and connection statistics are deliberately excluded — they are a record of what happened on this router, not configuration, and restoring them elsewhere would fabricate history.

Sensitivity
Treat the file like the database.

It contains the WireGuard server private key and every preshared key. Without the server key a restored router cannot talk to any existing client, so it has to be included — but anyone holding this file can impersonate the router.

Download configuration

Restore

Replaces all devices and forwards. Your administrator account is not touched, so a restore cannot lock you out or change who can sign in.

The restore runs as a single transaction: either the whole configuration is applied or none of it is. The kernel is rebuilt from the result immediately, so the panel and the firewall never disagree about what is in force.
