Re-synchronise the kernel

Rebuild now

Pushes the WireGuard peer set and the nftables ruleset from the database. This happens automatically after every change and every 60 seconds; the button is for when you want to be certain rather than wait.

Compact the database

VACUUM

Reclaims space left by deleted logs and statistics. Safe to run at any time, but it rewrites the whole file, so it briefly blocks writes.

Factory reset

Deletes every device, port forward, log, statistic and setting, including the WireGuard server key — every client configuration you have issued stops working. Your administrator account is kept so you are not locked out. Export the configuration first if you might want it back.

Restarting the service and rebooting the host are deliberately not offered here: wgrouter runs under a supervisor that owns its lifecycle, and a web button that can take the router off the network is a good way to lose access to the router.
